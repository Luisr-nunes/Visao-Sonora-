## About

Academic project at Cesar School, tied to UN Sustainable Development Goal 11 (Sustainable Cities and Communities). This repository holds the front end of the high-fidelity prototype, exported from Figma Make in React and TypeScript. Screens are mocked: there is no real speech recognition, geolocation or routing yet.

## The problem

More than 6.5 million people in Brazil have a visual impairment. Uneven sidewalks and unmarked construction limit their independence, and traditional maps are visual, so they are of little use to someone who cannot see the way.

## The solution

Visão Sonora does not look for the shortest route but for the safest and most accessible one. The interface is voice-controlled and guides the user step by step, warning ahead of obstacles, closures and danger spots.

| Feature | Description |
| --- | --- |
| Voice navigation | Fully voice-controlled interface ("Where am I?", "Navigate to...") |
| Safe routes | Prioritizes even sidewalks and audible traffic signals |
| Real-time alerts | Users report obstacles by voice, with crowd validation |
| Explore mode | Describes nearby points of interest and accessible businesses |

## Business models

| Model | Description |
| --- | --- |
| B2G | Licensing to governments as an official accessibility tool |
| B2C | Low-cost subscription with access to every feature |
| B2B | Businesses pay for an accessibility badge that highlights them on the map |

## Tech stack

- React 18, TypeScript and Vite 6
- shadcn/ui on top of Radix UI, Lucide
- CSS generated by Tailwind CSS
- Figma and Figma Make (prototyping and export), Google Sites (documentation)

## Running

Requirement: Node.js 18+.

```bash
git clone https://github.com/Luisr-nunes/Visao-Sonora-.git
cd Visao-Sonora-
npm install
npm run dev      # http://localhost:3000
```
